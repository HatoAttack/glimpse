# 手動確認表

自動テスト（`tests/ImageViewer.Tests`）で確かめられない、画面・エクスプローラーとのやり取り・更新を、人の手で確かめる表。
.NET の更新（#78）や画像ライブラリの置き換え（#81）など、アプリ全体に関わる変更の前と後で同じ表を使い、結果を比べる。

- 変更の前の版で一度すべて実施し、その結果を基準にする（期待結果と違っても、前の版と同じなら「変わらない」として扱う）
- 変更の後の版でもう一度実施し、前の版との違いがないことを確かめる
- 結果は下の「記録」に、版・日付・NG の項目だけを書く

## 準備

1. 使い捨ての画像を作る（`%TEMP%\glimpse-manual` に作る。あれば消して作り直す）

    ```
    powershell -ExecutionPolicy Bypass -File docs\manual-test-setup.ps1
    ```

    `images` に連番の JPEG 12 枚・PNG・透過 PNG・BMP・TIFF（1 ページと 3 ページ）・拡張子が PNG の TIFF・大きい JPEG（8000×6000）・ZIP（中に 3 枚）、`other` に 1 枚ができる

2. 手元の写真から、次を `images` にコピーする（無いものは、その項目を「対象なし」にする）
    - EXIF 付きの JPEG（縦向きで撮った写真があればなおよい）
    - アニメーション GIF と WEBP
    - HEIC（HEIF 画像拡張機能が入っている PC のみ）

3. 確かめる版を起動する。手元のビルドなら `dotnet run --project src/ImageViewer.App -c Release`、リリースなら `Glimpse.exe`
