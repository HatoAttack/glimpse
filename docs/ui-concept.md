# UI の作り直し（v1.0 に向けた設計メモ）

機能はそのままに、見た目と操作の置き場所を整理する。ショートカットと機能は変えない（新しく足すものだけ）。

コンセプトは **「画像が主役、道具は必要なときだけ」**。

- 上下の部品は細く、高さは状態によって変えない（選んでも一覧がずれない）
- 操作は、それが働く場所の近くに置く（サイドバーの切り替えは左、インスペクタの切り替えは右）
- 見始める左上にメニュー、よく使う操作ほど手前に
- Windows の作法（Fluent）に合わせる。Apple の HIG からは考え方だけ借りる（中身を主役に、インスペクタは右、確認より元に戻す）

画面のモックはデザインキャンバスにある（非公開。見る人には共有が必要）:
https://claude.ai/artifact/8P8SyhWtopoXzZH7rcCtty
最終形は 11（ふだん）・12（選択中）・8（インスペクタ）・7（1 枚表示＋詳細）・13（ダーク）。

## 画面の構成

```
┌──────────────────────────────────────────────────────────────┐
│ ☰ ▥ │ ← → ↑  [ ピクチャ › 2026 › 京都旅行          ]  名前順▾ ⓘ │ ツールバー 40px
├────────┬───────────────────────────────────┬─────────────────┤
│ホーム   │                                   │ 詳細             │
│よく開く │        サムネイル                   │ IMG_0142.jpg    │
│フォルダ │                                   │ 大きさ・形式…     │
│ （ツリー）│                                   │                 │
├────────┴───────────────────────────────────┴─────────────────┤
│ 画像 128 · フォルダ 2  ● チェック 3                   ▦ ━━●━━  │ フッター 32px
└──────────────────────────────────────────────────────────────┘
  サイドバー（左固定・隠せる）   グリッド              インスペクタ（右・開け閉め）
```

上下の部品の高さは合計 72px（今は メニュー＋ナビバー＋ステータスバー で約 83px）。

### ツールバー（40px。メニューバーとナビバーを 1 本に）

| 左から | 内容 |
|---|---|
| ☰ | メニュー（下記）。左上に置く（見始める場所。ウィンドウの ✕ から離す） |
| ▥ | サイドバーの表示 / 非表示 |
| ← → ↑ | 戻る / 進む / 上へ（今と同じショートカット） |
| アドレスバー | パンくず表示。クリック・Ctrl+L で入力。フォルダジャンプ・パス入力・コマンド検索を兼ねる（下記） |
| 名前順 ▾ | 並び順 |
| ⓘ | インスペクタの開け閉め（Ctrl+I） |

ボタンは 28px。

### ☰ メニュー

メニューバーにあった項目を、よく使う順に並べる。右クリックメニューは今のまま。

1. 移動: ホームへ・ホームの設定・フォルダへジャンプ・フォルダジャンプの設定
2. 表示: 並び順・手動の並び順を削除・サイドバー・インスペクタ・テーマ
3. チェック: すべてにチェック・反転・すべて外す（よく使うものは右クリックとフッターにもある）
4. 設定（MarkKey など）
5. ヘルプ: 対応形式・更新を確認・起動時に更新を確認

Alt キーでのメニュー（Alt+F など）はやめる。Alt で ☰ が開くようにする。

### サイドバー（左固定・表示 / 非表示の切り替えだけ）

- 上から ホーム → よく開く（`VisitHistory` から最大 5 件）→ フォルダツリー
- 右・上・下への配置は作らない（ツリーは縦に長いので上下では数行しか見えず、横長の画面では縦が貴重）

### インスペクタ（右側・開け閉め）

- 中身は文字だけ（プレビュー画像は入れない。サムネイルがあるので）
- ファイル名 / 大きさ（画素数）/ 形式・色空間 / ファイルサイズ / 更新日時 / 撮影日時 / カメラ / 撮影設定（F 値・シャッター速度・ISO）/ 場所
- 撮影日時・カメラ・撮影設定は EXIF から読む（新規）。選択が止まってから読む（今のフッターの情報と同じ `_infoDelay` の仕組み）
- 複数選択のときは枚数と合計サイズ
- 開け閉めの状態は settings.json に保存

### フッター（32px 固定）

高さは状態によって変えない。中身だけが入れ替わる。

| 状態 | 内容 |
|---|---|
| ふだん | 枚数・チェックの数 …… サイズのスライダー・ライト / ダークの切り替え |
| 選択中 | 対象 [選択 5 / ● チェック 3]・合計サイズ ｜ リサイズ・切り抜き・連結・名前・移動 ▾・⋯ …… 削除・✕ ｜ サイズのスライダー |

- **対象の切り替え**: チェックした画像に対して、選択し直さずに実行できる（今は Ctrl+¥ で選択してから）
- **移動 ▾**: 最近の移動先（今の最大 10 件の記録）をすぐ選べる。1〜3 のキー、Ctrl を押しながらでコピー。下に「フォルダーを探して移動 / コピー」
- **リサイズ ▾**（分割ボタン）: 本体は今の設定画面、▾ で前回の設定のまま実行。そのまま実行するのは新しいファイルを作るだけのときに限り、元の画像の置き換え・上書き・名前の重なりがあれば理由を出して設定画面を開く（Ctrl+Shift+R でも）
- ボタンの横にショートカットを表示する。幅が足りないときは ショートカットの表示 → ボタンの文字 の順に消す。スライダーは最後まで残す
- 削除とスライダーの間は区切り線で離す
- 右端はライト ↔ ダークの切り替えボタン（アイコンは今の配色。システムに合わせるのは ☰ → 表示 → テーマ）

### アドレスバー（ジャンプ＋パス＋コマンド）

- 入力するとフォルダ（今のフォルダジャンプ）とコマンド（登録済みの `IImageCommand` と、メニューの項目）を一緒に出す
- `>` で始めるとコマンドだけ
- Ctrl+L・Ctrl+J はどちらもここにフォーカスする

### 1 枚表示

- 上に 1 行（ファイル名・番号・チェックの数・倍率・閉じる）
- I キー / 「詳細」ボタンで右側に詳細パネル（中身はインスペクタと同じ）。画像に重ねず、画像は残りの幅に合わせる
- 開け閉めはインスペクタとは別に覚える（一覧では出したい、1 枚表示では画像を大きく、を両立）
- フィルムストリップ（前後の画像のサムネイルを下に 1 列）は、開いたときは出さず、← → かホイールで送り始めたときに下から出す。画像はそれに合わせて縮むアニメーションにする
  - 一度出したら閉じるまで出したまま（出たり消えたりが画面のずれになるため）。次に開いたときはまた出さない状態から
  - Space を押し続けている間（離したら閉じる見方）は、送っても出さない。ちらっと見るだけの表示なので画像の大きさを優先する
  - 最初の送りで「画像の切り替え」と「縮む動き」が重なる。忙しく見えないかは動かして確かめる
- Z を押している間だけ 100% で見る（ピントやノイズの確認用）
  - 画像の 1 画素を画面の 1 画素で、ぼかさずに描く。倍率は 100% だけ
  - 見える範囲はカーソルの位置で決まる（表示領域の端にカーソルがあれば、画像のその端が見える）。ドラッグは要らない
  - その画像だけ原寸で読み直す。読み終わるまでは今の画像を引き伸ばして見せる。読んだものは次の画像へ移る・閉じるまで持つ
  - ← → で送ったら画面に合わせた大きさに戻す。Space を押し続けている間（離したら閉じる見方）は使わない
- 開くときは、クリックしたサムネイルが一覧の位置から広がり、周りが暗くなる。閉じるときは今の画像のサムネイルの位置へ縮んで戻る（画面の外なら縮むだけ）
  - 0.15 秒くらいの短い動きにする（押し続けてちらっと見る使い方を待たせない）。Windows の「アニメーション効果」がオフなら動かさない
  - 動かすのはサムネイル（読み込み待ちの仮表示と同じもの）なので、その間に本来の画像を裏で読める
  - 背景をだんだん暗くするのが重ければ、暗くするのは一度にして、動くのはサムネイルだけにする
  - 動いている間は描く品質を落とし、止まったら高品質で描き直す（フィルムストリップで縮むときも同じ）

## 色とテーマ

- **ダークモードに対応する**。テーマは システムに合わせる（既定）/ ライト / ダーク
- 色はコードに直接書かず、テーマの色の一覧（背景・面・線・文字 3 段階・選択・チェック・危険）から使う。将来ほかの配色やアクセントの色を足せるようにするため
- 選択は青、チェックはオレンジ（今の色）だけを強調色にする
- WinForms の標準部品（ツリー・スクロールバー・メニュー・ダイアログ）とタイトルバーもテーマに合わせる（`SetWindowTheme` の DarkMode_Explorer、`DWMWA_USE_IMMERSIVE_DARK_MODE`、ToolStrip の Renderer）

| 役割 | ライト | ダーク |
|---|---|---|
| 背景 | `#F7F7F5` | `#1B1B1A` |
| 面（ツールバー・フッター・インスペクタ） | `#FFFFFF` | `#242423` |
| 線 | `#E4E4E0` | `#363633` |
| 文字 | `#1C1C1A` / `#3A3A37` / `#5F5F5A` | `#EDEDEA` / `#D6D6D1` / `#A8A8A2` |
| 選択（背景 / 枠 / 文字） | `#E6ECF7` / `#2F6BD8` / `#1D4FA3` | `#1F3354` / `#5B8FEA` / `#A9C5F5` |

## 作らないと決めたこと

| 案 | 理由 |
|---|---|
| メニューを右上（⋯）に集める | 左から見る順に合わず、ウィンドウの ✕ の近くで押し間違えやすい |
| 選択中に浮かぶアクションバー | 一番下のサムネイルに重なる |
| 選択中にフッターを高くする | 一覧の高さが変わる |
| 詳細にプレビュー画像 | サムネイルと重複 |
| 詳細を左カラムの下に | 1 枚表示の詳細（右）と場所がそろわない |
| サイドバーを右・上・下にも置ける | ツリーに向かない。手間の割に得るものが少ない |

### 色調補正

補正の処理は 1 つにして、1 枚ずつかける入り口と、まとめてかける入り口を用意する。細かい仕上げは外部アプリに任せ、ここでは画像全体にかける補正だけにする。

- 項目: 明るさ・コントラスト・彩度・レベル補正（黒点・白点・ガンマ）・自動補正
  - 自動補正はボタン 1 つ。レベルを自動で決め、結果はスライダーに反映して手で直せるようにする
- 1 枚ずつ: 1 枚表示の右側にパネルを出す（詳細パネルと同じ場所）
  - 表示中の画像にそのまま反映する。押している間だけ補正前に戻せる
  - 拡大や Z の 100% 表示でも補正後の見た目のまま
  - 保存は上書き
  - 調整した値を「前回の補正」として覚え、まとめてかけるときにも使える
- まとめて: 一覧で選んで、フッターの「補正」から。ダイアログに代表の 1 枚を出して確かめる。出力先はリサイズと同じ設定（サブフォルダ・同じフォルダ・上書き）
- JPEG / WEBP の画質は ☰ → 設定で決められるようにする。リサイズ・切り抜き・連結の保存にも同じ値を使う（今は 90 で固定）。EXIF は残す
