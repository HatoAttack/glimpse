# 機能の詳細

[README](../README.md) の「使い方」より詳しい、機能ごとの操作と設定項目の説明。

## 一覧と表示

- フォルダを開く: Ctrl+O・フォルダのドロップ・起動引数
- サムネイルグリッド: クリック / Ctrl / Shift / キー操作 / ドラッグ範囲選択で複数選択。サブフォルダもタイルで表示
- サムネイルの大きさ: フッターのスライダー / Ctrl+ホイール（64〜320。作る大きさは 4 段階で、段階をまたがなければ作り直さない）
- Quick Look: Space（短く押すと開いたまま / 押し続けると離したら閉じる）・ダブルクリックで大きく表示。表示中も ← → ¥ ^ が使える
- チェック: ¥ で付け外し（複数選択ならまとめて）、^ で付け外しして次へ、Shift+¥ で選択中にチェック、Ctrl+¥ でチェックした画像を選択。
  ¥ / ^ は `settings.json` の `MarkKey` / `MarkNextKey` で変更できる
- 並び順: 名前・更新日時・サイズ・手動。手動はドラッグで並べ替え、フォルダごとに保存
- 詳細パネル: 一覧の右側（ⓘ / Ctrl+I で開け閉め）と 1 枚表示の右側（I キー）。ファイル名・大きさ・形式・ファイルサイズ・更新日時と、
  撮影情報（撮影日時・カメラ・レンズ・F 値・シャッター速度・ISO。HEIC・RAW など Windows の拡張機能で読む形式は撮影日時とカメラだけ）・場所。
  1 枚表示の間は一覧の右のパネルを隠して画像を広く見せる
- フッター: 件数・チェックの数・選択中の画像の情報（1 枚: 解像度・形式・ファイルサイズ・更新日時 / 複数: 枚数と合計サイズ）・サムネイルの大きさ。
  画像を選んでいる間は同じ高さのまま操作ボタンに変わる（対象の切り替え［選択 / チェック］・リサイズ・切り抜き・連結・名前・移動 ▾・⋯・削除・選択を解除 Esc）。
  幅が足りないときはショートカットの表示 → 文字の順に省く
- 配色: システムに合わせる / ライト / ダーク（☰ → 表示 → テーマ。フッター右端のボタンでライト ↔ ダーク）。
  ダイアログもダークになる（Windows の確認メッセージ・フォルダの選択・色の選択の画面は Windows のまま）

## フォルダの移動

- ツールバー: ☰ メニュー（Alt / F10）・サイドバーの表示 / 非表示・戻る / 進む / 上へ・アドレスバー・並び順
- 戻る / 進む / 上へ: Alt+← / Alt+→ / Alt+↑・Backspace・マウスの戻る / 進むボタン
- アドレスバー: ふだんはパンくず（クリックでその階層へ。長いときは先頭を「…」に）、空いている所のクリック / Ctrl+L で入力（補完あり）。
  入力すると ☰ のコマンド（先に数件）とフォルダを一緒に出す。「>」で始めるとコマンドだけ（「>」だけで全部）。
  ひらがな / カタカナ・全角 / 半角は区別しない。今は実行できないコマンドは薄く出す
- フォルダジャンプ（Listary 風）: アドレスバーにフォルダ名の一部を入力すると候補を表示（Ctrl+J で空から入力）。
  スペース区切りで絞り込み（`2024 旅行`）、あいまい一致（`imgszch` → `image-sizechange`）、よく開く・最近開いたフォルダを上位に。
  自前の軽い索引（ユーザーフォルダ＋追加したフォルダ、最大 30 万件）。Everything との連携は設定で選んだ人だけ（同梱はしない）
- フォルダツリー: 左のサイドバー。表示 / 非表示を切り替えられる
- ホームフォルダ: Alt+Home / ☰ の移動で移動、起動時に開く、ツリーの先頭に表示（☰ の移動で設定。未設定ならピクチャ）

## ファイル操作

- 名前の変更（F2）: 文字列＋連番 / 置換・末尾追加 / 小文字化。プレビュー付き、2 段階で実行して失敗時は全部元に戻す、Ctrl+Z で元に戻す
- 新しいフォルダー（Ctrl+N / 右クリック）
- フォルダー名の変更: フォルダのタイルを 1 つ選んで F2 / ファイルメニュー / 右クリック（画像を選んでいるときの F2 は画像の名前の変更）
- 削除（Del / ファイルメニュー / 右クリック）: 選択中の画像をごみ箱へ移動（ごみ箱から元に戻せる。確認は複数枚のときだけ）。
  削除後は次の画像を選択、Quick Look 中なら次の画像を表示
- コピー / 切り取り / 貼り付け（Ctrl+C / Ctrl+X / Ctrl+V・編集メニュー・右クリック）: エクスプローラーと同じクリップボード形式なので、エクスプローラーとの間でも貼り付けられる。
  同じフォルダへのコピーは「- コピー」を付けて複製、同じ名前があれば Windows の上書きの確認。貼り付けたものを選択
- ドラッグ＆ドロップで移動 / コピー: 画像をフォルダのタイル・ツリーのフォルダに落とす（エクスプローラーからも）。
  エクスプローラーと同じく、同じドライブなら移動・別のドライブならコピー、Ctrl でコピー・Shift で移動。ツリーは止めておくと開く。
  エクスプローラー等へのドラッグも同じ規則で、移動された画像は一覧から外れる
- フォルダーへ移動（Ctrl+Shift+M）/ フォルダーへコピー（Ctrl+Shift+D）: 移動先はフォルダジャンプと同じ検索で選ぶ。入力が空なら最近の移動先（最大 10 件）。
  フッターの 移動 ▾ からは最近の移動先を 1〜9 のキーで選べる（Ctrl を押しながらでコピー）
- パスをコピー（Ctrl+Shift+C）

## 画像の編集

選択中の画像に対して、フッターのボタン・右クリックメニュー・☰ の「画像」から実行する。
チェックした画像は Ctrl+¥ で選択してから実行する。複数の画像は画面の並び順（手動で並べ替えた順）に処理する。
読み込みはビューアと同じなので HEIC / AVIF / RAW なども元にできる。

### リサイズ・形式変換（Ctrl+R）

| 項目 | 内容 |
|---|---|
| サイズ | 長辺 1600 / 1200 / 600 / 560 px・指定 px・変えない（形式の変換だけ）。既定では小さい画像は拡大しない |
| 形式 | 元のまま / JPG / PNG / WEBP（JPG は透過部分を白に。HEIC・RAW など書き出せない形式の「元のまま」は JPG） |
| 縮小の方法 | Bilinear / Bicubic / Lanczos |
| メタデータ | EXIF・XMP・IPTC を消す（既定。色の情報 ICC は残す）。回転は反映してから消すので向きは崩れない。HEIC・AVIF・RAW など Windows の拡張機能で読む形式は、残す設定でもメタデータを残せない（一覧に表示） |
| ファイル名 | 置換 → 末尾に付ける → 小文字化 |
| 出力先 | 中のフォルダ（既定 `resized`）/ 同じフォルダ / 指定のフォルダ。同名のファイルは飛ばす / 上書き |

- 実行前に「元の画像 → 出力」を一覧で確認できる。名前に \ などを含んで出力先の外に書いてしまうものはエラー。出力の名前が重なるもの（`a.jpg` と `a.png` を両方 PNG に など）はエラーとして示し、直すまで実行できない
- 元の画像を置き換えることになる設定（同じフォルダ・同じ名前・上書き）は確認してから実行する
- 保存は一時ファイルに書いてから差し替えるので、失敗・中断しても書きかけのファイルや壊れた元画像は残らない
- アニメーション（GIF / WEBP）は先頭のフレームだけの静止画になる。WEBP は縦横 16383px まで。JPG / WEBP は品質 90
- 設定は次回の初期値として覚える
- リサイズ ▾ / Ctrl+Shift+R: 前回の設定のまま実行（設定画面を出さない）。新しいファイルを作るだけのときに限り、
  元の画像の置き換え・上書き・名前の重なり・前回の設定なしのときは理由を出して設定画面を開く

### 切り抜き（Ctrl+K）

- 画像の上をドラッグで範囲を選ぶ。枠の中のドラッグで移動、四隅で大きさを変える
- アスペクト比: 自由 / 1:1 / 4:3 / 3:2 / 16:9 / 指定（W:H）。「縦横を入れ替え」で 3:4 など縦向きに
- 複数選択していれば ◀ ▶（PageUp / PageDown）で切り替え。Enter で「保存して次へ」
- 「全部を同じ比で中央から切り抜き」で選択中の全部を一括で
- 保存先は元と同じフォルダ（既定）か指定のフォルダ。名前は `元の名前_crop`（同名があれば ` (2)` などを付けて上書きしない）

### 連結（Ctrl+M、2 枚以上）

| 項目 | 内容 |
|---|---|
| 並べ方 | 横 / 縦 / グリッド（列の数） |
| 大きさ | 横は高さ・縦は幅を そのまま / 小さい方 / 大きい方 / 指定 px に揃える。グリッドは 元の一番大きい画像 / セルを指定 px 角に |
| 揃え | 横は上 / 中央 / 下、縦は左 / 中央 / 右 |
| 間隔・外の余白 | px で指定 |
| 背景 | 色（色の選択画面あり）/ 透明（JPG では白） |
| 形式 | PNG / JPG / WEBP |

- 設定を変えるとすぐプレビューに反映する。プレビューは縮小して読んだ画像（長辺 1200px まで・合計 1600 万画素まで）で組み、長辺 2400px のキャンバスに直接描くので、何百枚選んでもメモリは増えすぎない。原寸で読むのは保存するときだけ
- 仕上がりが形式の上限（WEBP 16383px・JPG 65535px）を超えるときは保存前に知らせ、とても大きいとき（2 億画素超）は確認する

## 対応形式

| 区分 | 形式 |
|---|---|
| どの PC でも読める（ImageSharp） | JPG / PNG / GIF / WEBP / BMP / TIFF / TGA / ICO / CUR / PBM 系 / QOI |
| Windows の拡張機能があれば読める（WIC） | HEIC / HEIF / AVIF / JPEG XL / 各社 RAW / JPEG XR / DDS など |

WIC の対応形式は起動時にその PC のデコーダを列挙して決まる（☰ →「ヘルプ → 対応形式」で確認できる）。
HEIC は「HEIF 画像拡張機能」＋「HEVC ビデオ拡張機能」、AVIF は「AV1 Video Extension」、RAW は「Raw Image Extension」が必要。

## 更新

- 起動時に 1 回だけ GitHub の最新リリースを確認し、新しければフッターと ☰ のヘルプに表示（作業は止めない）
- クリックで変更内容を見て「更新する / 後で / このバージョンは飛ばす」。更新はチェックサム（SHA-256）を確かめてから exe を入れ替えて再起動
- ☰ のヘルプで起動時の確認を止められる（「更新を確認」で手動でも確認できる）。開発用のビルドでは起動時に確認しない
