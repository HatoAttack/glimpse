# 機能の詳細

## 一覧と表示

| 操作 | キー・マウス |
|---|---|
| フォルダを開く | Ctrl+O・フォルダをドロップ |
| 選ぶ | クリック / Ctrl・Shift＋クリック / ドラッグで範囲選択 |
| 大きく表示（Quick Look） | Space（押し続けると離したときに閉じる）・ダブルクリック。表示中も ← → で前後へ |
| 2 枚並べて比べる | 画像を 2 枚だけ選んで Space。← → で替える側の画像を前後へ、Tab・クリックで替える側を切り替え、Z で 2 枚とも 100% |
| 100% で見る（ピント・ノイズの確認） | 大きく表示中に Z を押している間だけ。カーソルを動かすと見える場所が動く |
| アニメの一時停止 / コマ送り | 大きく表示中に P / , と .（GIF・WEBP のアニメ） |
| フレーム保存 | 大きく表示中に Ctrl+S（アニメの今のコマを PNG で保存） |
| 色調補正 | 大きく表示中に E（右側にパネル。Ctrl+S で上書き保存）。まとめてかけるのは Ctrl+Shift+E（→「画像の編集」） |
| チェックを付け外し | ¥（付けて次へは ^）。選択中にまとめて付けるのは Shift+¥ |
| チェックした画像を選ぶ | Ctrl+¥ |
| 詳細パネル | Ctrl+I・ⓘ（1 枚表示では I） |
| サムネイルの大きさ | Ctrl+ホイール・フッターのスライダー |

- **フィルムストリップ**: 大きく表示中に ← → で送り始めると、前後の画像のサムネイルが下に並びます。クリックでその画像へ移れます。閉じるまで出たままです（Space を押し続けて見ているときは出ません）
- **アニメ（GIF / WEBP）**: 大きく表示すると再生します。コマ送りをすると一時停止になります。Z で 100% を見ている間は止まり、そのコマを原寸で見られます。とても大きいもの（全部のコマを展開すると 1GB を超えるもの）は再生せず、先頭のコマだけを表示します
- **フレーム保存**: 今のコマを原寸の PNG で、元のファイルと同じフォルダに「元の名前_frame012.png」（012 は何コマ目か）で保存します。同じ名前があれば上書きせず (2) などを付けます
- **色調補正**: 明るさ・コントラスト・彩度・色温度・レベル補正（黒点・白点・ガンマ）を、表示中の画像にそのままかけて見せます（Z の 100% でも補正後の見た目）。「自動補正」は黒と白の位置と中間の明るさを画像から決めます。「補正前」を押している間は補正する前の画像に戻ります。スライダーはダブルクリックでその項目だけ元に戻ります
  - 保存は元のファイルへの上書きです（撮影情報は残ります）。HEIC・RAW など書き出せない形式は、元を残して同じ名前の JPG で保存します（撮影情報は残せないので、保存の前に確かめます）
  - 保存していない補正があるまま次の画像へ移る・閉じるときは、保存するか聞きます。保存した値は「前回の補正」で次の画像にもかけられます
  - アニメ（GIF / WEBP）や複数ページの TIFF では使えません（保存すると先頭の 1 枚だけになるため）
- **外での変更をすぐ反映**: エクスプローラーやほかのアプリで、開いているフォルダの画像を追加・削除・名前の変更・編集すると、一覧にすぐ反映します（選択と位置はそのまま。書き換えた画像はサムネイルも新しくなります）。大きく表示中の画像が消えたら次の画像を、書き換えられたら新しい中身を表示します。見張れないフォルダ（一部のネットワークドライブなど）は ☰ → ファイル →「再読み込み」（F5）で読み直せます
- **2 枚並べて比べる**: 似た写真からピントの良いものを選ぶとき向けです。左右に並べ、見出しに名前・何枚目か・縦横・ファイルの大きさを出します。片方が「替える側」（▸ と青い線）で、← → はその側だけを前後の画像に替えます（もう片方に出している画像は飛ばします）。Z を押している間は 2 枚とも 100% になり、カーソルの位置に合わせて 2 枚の同じ場所を見せます。¥ / ^ のチェックは替える側の画像に付きます。並べている 2 枚は一覧でも選んだままになるので、閉じてから Space でまた開けます
- **ZIP の中を見る**: ZIP（CBZ も）はフォルダのタイルとして並び、ダブルクリックで展開せずに中を見られます。ZIP の中では見るだけで、使えるのはコピー・フォルダーへコピー・エクスプローラーで表示・外へのドラッグ（どれもコピー）です。名前の変更・削除・補正などはできません
- **並び順**: 名前・更新日時・サイズ・手動。手動はドラッグで並べ替えて、フォルダごとに覚えます
- **詳細パネル**: ファイルの情報と撮影情報（撮影日時・カメラ・レンズ・F 値・シャッター速度・ISO）・場所を表示します
- **フッター**: 件数と選択中の画像の情報を表示します。画像を選ぶと、編集の操作ボタンに変わります
- **配色**: ☰ → 表示 → テーマで、システムに合わせる / ライト / ダークを選べます
- チェックのキー（¥ / ^）は `settings.json` の `MarkKey` / `MarkNextKey` で変えられます（Z にすると、100% で見る機能は使えなくなります）

## フォルダの移動

| 操作 | キー・マウス |
|---|---|
| 戻る / 進む / 上へ | Alt+← / Alt+→ / Alt+↑・Backspace・マウスの戻る / 進むボタン |
| ホームフォルダへ | Alt+Home |
| アドレスバーに入力 | Ctrl+L |
| フォルダジャンプ | Ctrl+J |

- **アドレスバー**: ふだんはパンくず表示です。入力するとフォルダとコマンドを一緒に探せます。「>」で始めるとコマンドだけを探します
- **フォルダジャンプ**: フォルダ名の一部を入れると候補を出します。スペースで区切って絞り込めて（`2024 旅行`）、あいまいでも見つかります（`imgszch` → `image-sizechange`）。よく開くフォルダほど上に出ます
- **検索の範囲**: ユーザーフォルダが対象です。ほかのフォルダは ☰ → 移動 →「フォルダジャンプの設定」で追加できます
- **ホームフォルダ**: 起動時に開くフォルダです。☰ → 移動で設定します（未設定ならピクチャ）
- **前回のフォルダから始める**: ☰ → 移動 →「起動時に前回のフォルダを開く」をオンにすると、ホームではなく前回終了したときのフォルダ（ZIP の中も）を開きます。そのフォルダが無くなっていればホームを開きます

### Everything との連携（任意）

[Everything](https://www.voidtools.com/) を使っている人は、フォルダジャンプの検索を Everything に任せられます。別のドライブなども含めて、Everything が知っているフォルダ全部から探せます。

1. Everything をインストールして起動しておきます（このアプリには同梱していません）
2. ☰ → 移動 →「フォルダジャンプの設定」で「Everything が起動していれば Everything で検索する」にチェックします

Everything が起動していないときは、いつもの検索に戻ります。フォルダーへ移動 / コピー の移動先を探すときにも使われます。

## ファイル操作

| 操作 | キー |
|---|---|
| 名前の変更 | F2 |
| 新しいフォルダー | Ctrl+N |
| コピー / 切り取り / 貼り付け | Ctrl+C / Ctrl+X / Ctrl+V |
| フォルダーへ移動 / コピー | Ctrl+Shift+M / Ctrl+Shift+D |
| パスをコピー | Ctrl+Shift+C |
| ごみ箱へ削除 | Del |
| 元に戻す（名前の変更） | Ctrl+Z |

- **名前の変更**: 画像を複数選んでいれば、連番（`snap##` のように # の数が桁数）・置換・末尾に追加・小文字化でまとめて変えられます。プレビューで確かめてから実行します
- **名前を直接入力**: 1 つだけ選んでいる画像・フォルダの名前をもう一度クリックすると、エクスプローラーと同じようにその場で名前を入力できます。Enter かほかをクリックで確定、Esc でやめます（画像の名前の変更は Ctrl+Z で元に戻せます）
- **コピー / 貼り付け・ドラッグ＆ドロップ**: エクスプローラーとの間でもやり取りできます。ドラッグはエクスプローラーと同じく、同じドライブなら移動、別のドライブならコピーです（Ctrl でコピー、Shift で移動）。フォルダのタイルを選んで Ctrl+C を押すとフォルダごとコピーでき、エクスプローラーや FTP ソフト（貼り付けに対応したもの）へそのまま貼り付けられます
- **フォルダーへ移動 / コピー**: 移動先はフォルダジャンプと同じように探せます。フッターの「移動 ▾」からは、最近の移動先を 1〜9 のキーで選べます

## 画像の編集

選んだ画像に、フッターのボタン・右クリックメニュー・☰ の「画像」から実行します。複数の画像は画面の並び順に処理します。
どの編集も、実行前に仕上がりや出力するファイルを確認できます。切り抜き・モザイク / ぼかし・補正は、保存のボタンの横の「上書き保存」で元の画像を置き換えます（確認は出しません。回転もエクスプローラーと同じく、確認せずにすぐ回します）。

### リサイズ・形式変換（Ctrl+R）

| 項目 | 選べるもの |
|---|---|
| サイズ | 長辺 1600 / 1200 / 600 / 560 px・指定 px・変えない |
| 形式 | 元のまま / JPG / PNG / WEBP |
| 縮小の方法 | Bilinear / Bicubic / Lanczos |
| メタデータ | 消す（既定）/ 残す（HEIC・AVIF・RAW などは残せない） |
| ファイル名 | 置換・末尾に追加（チェックで付ける / 付けないを切り替え。オフでも文字列は覚えておく）・小文字化 |
| 出力先 | 中のフォルダ（既定 `resized`）/ 同じフォルダ / 指定のフォルダ |

- 設定は次回も使えるように覚えます。Ctrl+Shift+R（フッターの「リサイズ ▾」）なら、前回の設定のまま設定画面を出さずに実行します（元の画像を置き換える・上書きする・名前が重なるときなどは、理由を出して設定画面を開きます）
- 小さい画像は既定では拡大しません
- メタデータを消しても、向きと色の情報は保たれます
- アニメーション（GIF / WEBP）は先頭のフレームだけの静止画になります

### 回転

フッターの「回転 ▾」・右クリックメニュー・☰ の「画像」から、右に 90°・左に 90°・180° を選びます。

- 画素を回して元のファイルに上書きします（どのソフトでも同じ向きに見えるように）。JPG / WEBP は保存し直すので、「保存の画質」で圧縮し直します
- EXIF の向きが付いた写真は、見えている向きから回します。撮影情報は残します
- アニメーション（GIF / WEBP）・複数ページの TIFF・HEIC / RAW など書き出せない形式は回しません

### 切り抜き（Ctrl+K）

- 画像の上をドラッグして範囲を選びます
- アスペクト比: 自由 / 1:1 / 4:3 / 3:2 / 16:9 / 指定。縦向きにもできます
- 複数枚なら PageUp / PageDown で切り替え、Enter で保存して次へ進みます。全部を同じ比で中央から切り抜くこともできます
- 「次の画像も同じ位置で切り抜く」をオンにすると、切り替えても枠の位置と大きさをそのまま使います（スクリーンショットのように、大きさと構成が同じ画像向け）。大きさが違う画像には、画像に対する割合で合わせます（アスペクト比は保ちます）。このとき一括のボタンは「全部を今の範囲で切り抜き」になります。位置を覚えるのはダイアログを開いている間だけです
- 「保存」は 元と同じフォルダ / 指定のフォルダ に `元の名前_crop` という名前で保存します
- 「上書き保存」は、元のファイルを切り抜いた画像で置き換えます（撮影情報は残します。確認は出しません）。「上書きして次へ」（Shift+Enter）・「全部を上書き」もあります。HEIC・RAW など書き出せない形式、アニメーションや複数ページの画像は上書きしません

### モザイク・ぼかし（Ctrl+B）

画像の中の選んだ範囲だけに、モザイクかぼかしをかけます（顔・名前・番号などを隠すとき向け）。

- 画像の上をドラッグして範囲を選びます。範囲はいくつでも選べます。範囲の形は 四角 / 円・楕円 / 自由（隠したい所のまわりをドラッグでなぞった形）から選べます
- 範囲の中をドラッグで移動、選んだ範囲の四隅で大きさを変えます（円や自由な形も外枠ごと伸び縮みします）。Delete か右クリックで範囲を消します
- かけ方は モザイク / ぼかし / ボックスぼかし / 塗りつぶし（黒）から、強さは 1〜10 から選べます（塗りつぶしは強さを使いません）。ぼかしは弱いと文字などを推測されることがあるので、読まれては困るものには強めのモザイクか塗りつぶしを使ってください。強さは画像の長い辺に対する割合なので、大きさの違う画像にも同じくらいにかかります。表示はかけた後の見た目です（縮小した画像にかけているので、細かいところは保存したものと少し違います）
- 複数枚なら PageUp / PageDown で切り替え、Enter で保存して次へ進みます。選んだ範囲は、ダイアログを開いている間は画像ごとに覚えます
- 「次の画像も同じ範囲にかける」をオンにすると、切り替えても範囲をそのまま使います（スクリーンショットの同じところを隠すとき向け）。大きさが違う画像には、画像に対する割合で合わせます。このとき「全部に同じ範囲でかける」で、選んだ画像全部にまとめてかけられます
- 「保存」は 元と同じフォルダ / 指定のフォルダ に `元の名前_mosaic`（ぼかしは `_blur`、ボックスぼかしは `_boxblur`、塗りつぶしは `_fill`）という名前で保存します
- 「上書き保存」（「上書きして次へ」Shift+Enter・「全部を上書き」）は切り抜きと同じです（元のファイルを置き換えます。確認は出しません）

### 補正（Ctrl+Shift+E）

選んだ画像に同じ色調補正をまとめてかけます（1 枚だけなら大きく表示中の E でも補正できます）。

- 左に選んだ画像の 1 枚を補正後の見た目で出します。◀ ▶（PageUp / PageDown）でほかの画像に切り替えて確かめられます。「補正前」を押している間は補正する前の画像に戻ります
- 項目は 1 枚表示と同じです（明るさ・コントラスト・彩度・色温度・レベル補正・自動補正）。最初は「前回の補正」の値が入っています
- 「レベル補正は 1 枚ずつ自動で決める」をオンにすると、黒点・白点・ガンマを画像ごとに自動補正で決めます（明るさの違う写真をそろえるとき向け）。ほかの項目は全部に同じ値をかけます
- 形式は元のままです。HEIC・RAW など書き出せない形式は、同じ名前の JPG で保存します。撮影情報（EXIF）は残します（HEIC・RAW などは残せません）
- 出力先は 中のフォルダ（既定 `adjusted`）/ 同じフォルダ / 指定のフォルダ。同名のファイルがあるときは飛ばすか上書きするかを選べます。「上書き保存」なら、出力先の設定に関わらず元の画像を置き換えます（確認は出しません。HEIC・RAW などは元を残して同じ名前の JPG に）
- アニメーション（GIF / WEBP）や複数ページの TIFF は補正しません（失敗として数えます）
- 実行した値は「前回の補正」として覚え、1 枚表示でも使えます

### 連結（Ctrl+M、2 枚以上）

| 項目 | 選べるもの |
|---|---|
| 並べ方 | 横 / 縦 / グリッド |
| 大きさ | そのまま / 小さい方・大きい方・指定 px に揃える |
| 揃え | 上・中央・下（縦なら左・中央・右） |
| 間隔・余白 | px で指定 |
| 背景 | 色 / 透明 |
| 形式 | PNG / JPG / WEBP |

設定を変えると、すぐプレビューに反映します。

### 保存の画質

JPG / WEBP で保存するときの画質（1〜100、既定 90）は ☰ → 画像 →「保存の画質」で変えられます。リサイズ・切り抜き・モザイク / ぼかし・回転・補正・連結のどれにも同じ値を使います。

## 対応形式

| 区分 | 形式 |
|---|---|
| そのまま読める | JPG / PNG / GIF / WEBP / BMP / TIFF / TGA / ICO / QOI など |
| Windows の拡張機能があれば読める | HEIC / AVIF / JPEG XL / 各社 RAW など |

拡張機能は Microsoft Store から入れられます（HEIC は「HEIF 画像拡張機能」と「HEVC ビデオ拡張機能」、AVIF は「AV1 Video Extension」、RAW は「Raw Image Extension」）。
その PC で読める形式は ☰ → ヘルプ →「対応形式」で確認できます。

## 更新

起動時に新しいバージョンを確認し、あればフッターでお知らせします。クリックすると変更内容を見て、そのまま更新できます。
確認を止めたいときは ☰ → ヘルプで切り替えられます。
